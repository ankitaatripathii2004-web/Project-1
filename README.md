🎮 Tic Tac Toe

🔗 Live Demo: https://mygametctactoe.netlify.app/

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. Play against a friend in this classic two-player game with smooth animations and sound effects!

🚀 Features

🎮 Two-player mode (X & O)

✨ Interactive UI with smooth animations

🔊 Sound effects on click, draw & win

📱 Fully responsive design (Mobile + Desktop)

🧠 Real-time win & draw detection

🔁 Restart game functionality

🛠️ Technologies Used

HTML – Structure of the game

CSS – Styling, layout & animations

JavaScript – Game logic & interactivity

🎯 How to Play

Open the live demo link above OR Run index.html in your browser.

Player X starts first.

Players take turns placing X and O on the grid.

The first player to get three marks in a row (horizontal, vertical, or diagonal) wins 🏆

If all 9 cells are filled and no player wins, the game ends in a draw 🤝
